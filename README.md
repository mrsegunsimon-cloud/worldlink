# WorldLink

One Flutter codebase for Android and iPhone: video feed, World Tourism Centres (57 destinations with photos), music player, SOS.

- Android: GitHub Actions > "Android build" produces `worldlink-android-apk`.
- iPhone: "iPhone build" (manual run) compiles unsigned; installing on a phone needs an Apple Developer account.
- Photo credits are in `assets/data/destinations.json`. Demo songs and videos are original synthesized content.

Next: sign-up/login, camera with face and voice effects, video calls.
